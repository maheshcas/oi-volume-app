Trap card
frontend/src/components/TrapCard.tsx
- Trap card supports:
  - trap_direction
  - trap_affected_level
  - direction-aware suggested action
- Direction pill semantics:
  - upside = danger family
  - downside = amber warning family
- Trap type text is neutral, not direction-colored.
- Affected level guard:
  - downside must not resolve to an invalid level above resistance; it falls back to support
  - upside must not resolve to an invalid level below support; it falls back to resistance

Key levels card
frontend/src/components/KeyLevelsCard.tsx
- Current labels:
  - Support
  - Resistance
  - Confirm Above
  - Next Resistance
  - Next Support
- Guard rules:
  - Next Resistance only renders if strictly above active resistance
  - Next Support only renders if strictly below active support
  - invalid structural values should be suppressed rather than mislabeled

Structural Price Context
frontend/src/components/StructuralPriceContextCard.tsx
- SPC is compact-first.
- Current compact content:
  - Bias chip
  - Regime chip
  - support / spot / resistance
  - spot position in band
  - distance-to-boundary hints
  - band width
  - directional targets
- Chart is behind a Show Chart / Hide Chart toggle.
- Target cards should read directionally:
  - Upside Target
  - Downside Target
- Range track supports preserved previous-level breach markers when backend data exists.
- Validation note:
  - if no mark appears, first check whether backend actually provides a distinct previous level and confirmed breach state

Web field mapping
frontend/src/App.tsx
- Spot:
  - index-data quote still updates faster than option-chain fallback
  - local browser runtime must not cache `/api` responses through the service worker
- Key levels:
  - support = intelligence.levels.support.strike
  - resistance = intelligence.levels.resistance.strike
- Trap:
  - trap_direction and trap_affected_level are normalized again at the frontend display layer to avoid impossible values leaking to UI
- Targets:
  - live market-state targets are preferred by structural side, not just by bias label
