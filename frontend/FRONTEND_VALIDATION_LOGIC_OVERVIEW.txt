Frontend Data Contract
- The mobile layout uses the same response already fetched in App.tsx.
- No backend API changes are required.
- Primary mappings:
  - tradeAction:
    - market_state.trade_action
  - resolvedReason:
    - market_state.resolved_reason
    - fallback: market_state.decision_explanation
  - readiness:
    - market_state.trade_readiness
    - market_state.readiness_state
    - market_state.readiness_active
  - structure:
    - levels.support.strike
    - levels.resistance.strike
  - trap:
    - signals.trap.trap_probability
    - signals.trap.trap_type
  - absorption:
    - market_state.absorption_detected
    - market_state.absorption_message
    - market_state.absorption_level
    - market_state.support_transition_active
  - session:
    - market_state.session_phase
    - market_state.regime
    - market_state.pressure_state
  - decision layer:
    - institutional_structure.put_wall
    - institutional_structure.call_wall
    - frontend-derived bullish / bearish triggers
  - ladder:
    - compact slice of displayRows near ATM
  - writers:
    - frontend-derived top CE / PE writers from DeltaOI and volume
  - basis:
    - frontend-derived synthetic future and basis
  - alerts:
    - displayAlerts

Defensive Rendering Rules
- Missing numeric values display as "-".
- Empty ladder data shows a placeholder card.
- Empty writers data shows a placeholder state.
- Absorption card hides when there is no absorption signal/message.
- Alerts card hides when there are no alerts.
- Bottom nav is static UI only and does not change app routing.

Visual Intent
- Dark mobile trading layout
- Compact, vertical, signal-first blocks
- Primary signal card is the dominant decision surface
- Strike ladder is simplified for small screens
- Wide desktop tables are not reused directly on mobile

Validation Checklist
- Open app below md width and confirm mobile layout renders instead of desktop.
- Open app at md and above and confirm desktop layout is unchanged.
- Symbol pills switch symbol using existing App state.
- Expiry pills switch expiry using existing App state.
- Spot hero shows spot, change, PCR, updated time without layout overflow.
- Primary signal card shows:
  - trade action
  - reason
  - readiness bar
  - bias
  - pressure
  - regime
  - readiness state
- Absorption card appears only when absorption is active or a message exists.
- Trap card shows probability, type, and explanation.
- Key levels card shows support, resistance, and breakout probabilities.
- Decision layer shows put wall, call wall, bull trigger, bear trigger.
- Strike ladder highlights ATM / support / resistance rows when present.
- Top writers tab switch works between CE and PE.
- Futures basis card renders basis state correctly.
- Alerts card renders up to four alert messages cleanly.
- Bottom nav remains fixed and does not hide content behind it.
